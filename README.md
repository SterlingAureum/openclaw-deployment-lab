# OpenClaw Deployment Lab

A reproducible deployment & security blueprint for OpenClaw onboarding in **no-provider / no-channel / no-skills** baseline mode.
This repository focuses on **operability, security defaults, and handover documentation** so the setup can be repeated across client servers.

## Scope (v1)
- QuickStart onboarding
- Gateway defaults validated (bind=127.0.0.1, token auth, port=18789)
- No model provider credentials (intentional)
- No chat channels configured (intentional)
- No skills installed (intentional)
